# Service glossary

- **Brownfield**: existing device configuration that must be modeled without changing live behavior.
- **Coverage diff**: the diff between original brownfield XML and regenerated XML from discovered services.
- **CFS**: customer-facing service layer.
- **RFS**: resource-facing service layer.
- **Leftover config**: temporary service coverage used to keep a discovery iteration moving while a gap remains unresolved.
- **Reconcile**: the point where NSO takes ownership of existing config after coverage is acceptable.
- **No-networking**: NSO re-deploy mode used to regenerate configuration locally without touching the device.
